# Código de Conduta

Este projeto adota o [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: seja respeitoso, construtivo e inclusivo. Assédio, discriminação, ataques pessoais e
publicação de dados privados de terceiros (incluindo trechos de reuniões reais) não são aceitos.

Problemas de conduta podem ser relatados em sigilo ao mantenedor pelo
[relato privado do GitHub](https://github.com/carlos-dataengineer/fluxoorg/security/advisories/new)
ou pelo perfil [@carlos-dataengineer](https://github.com/carlos-dataengineer). Todo relato é analisado
com discrição, e as medidas seguem as diretrizes de aplicação do Contributor Covenant.
